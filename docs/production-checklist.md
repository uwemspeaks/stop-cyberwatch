# Production handoff checklist

Before accepting real reports:
- Approve the privacy notice and retention schedule.
- Decide anonymous-report and follow-up policy.
- Configure private evidence storage.
- Implement server-side validation, rate limiting and spam controls.
- Configure reviewer/admin authentication and role-based access.
- Add and test row-level security.
- Add audit logging and secure reference generation.
- Restrict file types and sizes; add malware scanning.
- Review data protection obligations and legal wording.
- Confirm the internal S.T.O.P. report-handling process.

Academy content:
The 40 scenario entries demonstrate the game engine and category distribution. Some question patterns are repeated to demonstrate the mechanics. They are not 40 fully distinct expert-authored investigations. Replace or expand them with scenario-specific facts, evidence packs and answer rationales before formal training.

Keep simulated mission data separate from real report data. Never expose report records, evidence files or internal notes through public game endpoints.
